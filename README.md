# 우리 가족 가계부
접속: https://kyrkyr0319-code.github.io/family-ledger/

## 사용
이메일·비밀번호·표시 이름으로 가입합니다. 기존 Supabase 프로젝트의 이메일 확인 없는 자동 로그인 설정을 변경 없이 사용합니다.
첫 가족은 ‘새 가족 가계부 만들기’를 누르고, 표시된 코드를 가족에게 직접 전달합니다. 다른 가족 구성원은 각자 가입한 뒤 ‘초대 코드로 참여하기’를 사용합니다.
코드는 7일간 유효하며 생성자가 재발급하면 기존 코드는 무효화됩니다.
각자의 거래를 입력·수정·삭제하고 공동 월별 내역을 확인합니다. 차액은 실제 통장 잔액이 아닙니다.
GitHub Pages는 main 브랜치 루트의 index.html을 배포합니다. Supabase JavaScript 2.57.4와 공개용 키만 사용합니다.
기존 memos 테이블은 변경하지 않았습니다. schema.sql은 이미 적용된 초기 스키마 기록이므로 재실행하지 않습니다.

## 검증 (2026-10-30)
- 배포 사이트 첫 화면·스크립트 로딩: 브라우저 확인.
- 별도 가상 계정 4개로 가입·자동 로그인·독립 로그인 세션: API 확인.
- 가족 생성·초대 참여·초대 생성자 권한·재발급 전 코드 거부: API 확인.
- 만료 코드 거부: 롤백 트랜잭션에서 서버 함수 확인.
- 두 계정 동시 저장·수입/지출 차액·본인 수정/삭제·재로그인 후 유지: API 확인.
- 다른 작성자의 수정/삭제, 타 가족·미가입 계정 조회, 소속/작성자 변경, 임의 가입 차단: RLS/API 확인.
- 양수 금액·분류 검사 및 네 테이블의 RLS 활성화 확인.
- 실시간 연결 전 토큰 설정을 보완한 후, 추가/수정/삭제 알림 3건을 같은 가족에서 수신하고 다른 가족의 수신 0건 확인.
- 로그인 이후 실제 브라우저 조작, 모바일 실기기 화면, 브라우저 새로고침·연결 복구는 미검증. 서버/API 검증과 구분합니다.
- 기존 프로젝트의 유출 비밀번호 차단 기능 비활성 경고는 유지했습니다: https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection
